# gobblet-lite 套娃棋

极简版 Gobblet（套娃棋）：4×4 棋盘，每位玩家有大、中、小三种棋子，
**大棋子可以盖住小棋子**——被盖住的棋子还留在下面，随时可能被掀开。
先连成横/竖/斜 4 子一线者胜。纯 Python 标准库，零依赖。

## 玩法

- 你是甲（●），AI 是乙（○）；大=3 / 中=2 / 小=1。
- 每人场外有 3 个堆，每堆按大→中→小叠放，**只能取每堆顶部**（小的先上场）。
- 每回合二选一：
  - **落子**：从场外某堆顶部取一子，放到空格，或盖住一个更小的棋子；
  - **走子**：把盘上某个己方顶部棋子移到另一格（空格，或盖住更小的棋子）。
- **记忆规则**：走子掀开底牌也算数——若你挪开自己的棋子露出了对方的四连，
  判对方胜；若同一步双方四连同时形成，**走子方优先**获胜。
- 无棋可走判负；400 半回合未分胜负判和棋。

## 运行

```bash
python3 -m gobblet_lite              # 人机对战（你是甲）
python3 -m gobblet_lite --ai-first   # AI 先手
python3 -m gobblet_lite --auto --games 10 --seed 42   # AI 对 AI 演示
python3 -m gobblet_lite --auto --games 5 --verbose    # 打印每步
```

交互命令（坐标 a1–d4，左上为 a1）：

```
d <堆号1-3> <坐标>   落子, 例: d 1 b2
m <起点> <终点>      走子, 例: m b2 c3
q                    退出
```

## AI 说明

贪心 1 步 AI：有直接获胜走法必走；否则尝试拆掉对方全部即胜走法；
再按"盖住对方棋子 > 占中心 > 随机"选。能走出即胜、会挡明显的四连，
但不会做多步连珠规划，熟悉规则的人类通常能赢。

## 真实验证记录

- `py_compile`：通过。
- 9 项单元测试（`/tmp/test_gobblet.py`，真实执行）：大盖小 / 小不能盖大 /
  四连获胜 / 掀开对方四连判对方胜 / 同步四连走子方优先 / 非法走法拒绝
  （空堆、动对方子、同尺寸、越界）/ 堆叠顺序（小→中→大）/ AI 必走即胜 /
  自动对局正常结束——**全部通过**。
- `--auto --games 10 --seed 42`：10 局全部自然结束，
  甲胜 6 / 乙胜 4 / 和棋 0，22–106 半回合/局，约 1.5 秒跑完。

## 已知局限（诚实版）

- **简化规则**：原版 Gobblet 每人 12 子（4 种尺寸×3 堆），这里简化为 9 子
  （3 种尺寸×3 堆）；记忆规则只实现"走子方优先"，未实现原版全部细节。
- AI 只是 1 步贪心，不做深层搜索；残局偶尔出现互盖拉锯（400 半回合上限兜底）。
- 文本棋盘，无图形界面/存档/悔棋；需要 Python 3.10+。
